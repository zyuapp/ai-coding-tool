B — Ref chips + select panel

recommended

Straight from the merge line in the screenshot: the ref is an accent-tinted monospace chip with a branch or commit glyph, and the word Base / Compare drops back to plain quiet prose. No box around the whole control — the chip already reads as pressable. The menu becomes a Primer SelectPanel: titled header, filter field, Branches / Tags tabs, tick on the left, and a meta column on the right (default, last commit age). Click either chip.

C — One compare bar

tightest

GitHub's compare page reads base … compare as a single control. Here the two sides share one bordered track split by that same ... cell, which buys back ~14px of gutter and says outright that the two belong to one comparison. The separator is deliberately not an arrow: an arrow between two refs reads as merge base into compare, which is not what the panel does. Each half still opens its own select panel; the right half anchors its panel to the right edge so it cannot fall off a narrow dock.
